Priority order for our epics (milestones). Backlog.md has no native milestone ordering, so **this doc is the source of truth** for what we work on next. Keep **Now** to 1–2 epics — that's the whole point.

How to use it:
- **Now** — the 1–2 epics in active focus. Tag their tasks with the `focus` label so `backlog task list --labels focus` shows today's work.
- **Next** — queued up; promote into Now as Now empties.
- **Later** — everything else, unordered until it earns a slot.

To re-prioritise, move an epic's link to a different column. When an epic ships, delete it. Each link opens that epic's swimlane in the web UI (`backlog browser` must be running on port 6420).
